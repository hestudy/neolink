### 架构技术细节

#### Puppeteer 集成规范

[Source: docs/architecture.md#内容提取服务集成]

**文件位置**: `packages/ai/src/services/ContentExtractionService.ts`

**核心接口**:

```typescript
interface ExtractedContent {
  url: string;
  title: string;
  description: string;
  favicon: string;
  author: string;
  content: string;
  textContent: string;
  screenshot: string;
  extractedAt: Date;
}

interface ContentConfig {
  userAgent: string;
  timeout: number;
  viewport: { width: number; height: number };
}
```

**浏览器配置**:

```typescript
await puppeteer.launch({
  headless: true,
  args: [
    '--no-sandbox',
    '--disable-setuid-sandbox',
    '--disable-dev-shm-usage',
    '--disable-gpu',
  ],
});
```

**页面配置**:

- 视口: 1200x800
- 等待策略: 'networkidle2'
- 超时: 30000ms
- User-Agent: 配置化

#### 错误处理策略

[Source: docs/architecture.md#内容提取服务集成]

1. **网络超时**: 30秒超时，返回基础信息
2. **页面加载失败**: 降级到 HTTP HEAD 请求获取基础元数据
3. **JavaScript 错误**: 忽略 JS 错误，继续提取静态内容
4. **浏览器崩溃**: 重启浏览器实例，重试一次
